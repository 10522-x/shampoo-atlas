## 已落盘的结构与行为

| 范围 | 修复后的行为与维护位置 |
| --- | --- |
| 模块与排序 | 每条记录的 `module`／`order` 决定归属和顺序；删除旧 `block`／`rank`。`modules.js` 只保留模块定义与排序函数，不再复制成分 ID 清单。未知模块直接报错，避免静默隐藏成分。 |
| 人群条件 | 用人工审校的 `suitableFor`／`avoidFor` 表达受控头皮、发质与状态；`best`／`avoid` 为这些条件的显示标签，不再解析原始自由文案。 |
| 匹配资格 | `consumerMatch` 控制正向推荐，`isDrug` 阻止药用条目成为普通发质推荐；避开规则仍独立处理。配方辅助成分不按发质正向推荐。 |
| 独立注意事项 | 个人过敏史与需要人工核对的风险放入 `cautions`，配方条件保留在 `synergy`，地区限制放入 `regulatory`；这些文案不生成用户属性。 |
| 名称与搜索 | `inci` 保留核对后的英文名称，`abbr` 放可明确识别的缩写，`aliases` 保存旧名称及显式标签别名。网页和 skill 使用相同的名称规范化逻辑。 |
| 引用 | `refs` 保存题名、链接、核实标记与支持范围；保留未定位的原始出处并标注待核实。删除没有统一标准的原 `grade`，不补造 A/B/C/D 功效等级。 |
| 数据校验 | 检查身份唯一、模块与顺序合法、受控条件有效、别名无精确冲突，以及网站／skill 文件哈希与别名快照一致。 |

一个规则内不同维度必须同时满足；同一维度的允许值按该字段语义匹配，多个状态要求全部选中。推荐与避开冲突时归入避开。未命中、信息不足或中性的成分保留在总库中，不强行分进定制表。清空选择恢复完整总表。

例如，粗硬发不再触发苯甲醇推荐，油性头皮不再触发卡波姆、食盐或 EDTA 推荐；APG 的已知过敏事项不会被当成“敏感头皮”属性。头屑选项不生成疾病诊断，也不触发酮康唑或二硫化硒的普通发质推荐。

实现与验证入口：[matching.js](../src/lib/matching.js)、[validation.js](../src/lib/validation.js)、[names.js](../src/lib/names.js)、[匹配行为验证](../test/matching.test.js)、[skill 验证](../test/shampoo-skill.test.js)、[数据校验脚本](../scripts/validate-data.mjs)。

## 已核实后修正的内容

详细依据按核对范围保存，不能把某篇来源存在理解为整个成分条目都已经验证：

| 核对记录 | 本轮修正重点 |
| --- | --- |
| [科学事实与文案](review-science.md) | 修正 BTMS 的甲基硫酸根释义；移除 APG 对严重接触性皮炎的确定推荐；补充已知葡糖苷、DMAPA 及特定水解小麦蛋白过敏注意事项；删除泛醇发干代谢、精确弹性百分比、蛋白重建发芯及硅油零堆积等无可靠出处断言。区分体外、动物、口服、外用与具体洗发水试验，不据此承诺未知浓度成品的生发／控油效果。 |
| [法规与药用条目](review-regulatory.md) | 按用途区分欧盟西曲氯铵和氯咪巴唑的限量；修正吡硫翁锌禁用依据与日期；记录 D5／D6 的 REACH 条款及解释边界；酮康唑、二硫化硒按具体药品标签说明，修正“头皮银屑糠疹”。 |
| [名称与精确别名](review-names.md) | 清理 INCI 中的缩写／说明后缀；核对部分植物名称与标签别名；补齐荷荷巴种子油、迷迭香、锯叶棕及已确认中文植物标签形式的精确识别；保留旧名与“瓜儿胶”拼写别名。 |

`refs[].verified: true` 仅表示引用记录及其 **`scope` 内的内容**已核对。名称词汇表只能支持名称；法规条款只能支持注明地区、用途与范围的要求；体外或动物研究不证明人体成品效果。某条记录包含已核对的名称引用，不代表其原始功效文献也已核实。

## 未原样采纳的建议

- **不把安全评估直接当成功效 A 级**，也不为全部条目机械重排 A/B/C/D；证据用途和支持范围比一个统一字母更准确。
- **不补写未经核实的 SLS 精确 CMC 或统一刺激性排序**；删除原来的错误表述，保留浓度与复配条件边界。
- **不把无显著差异写成等效**；迷迭香试验中的 2% 指米诺地尔，摘要未给出迷迭香油浓度，且并非洗发水试验。
- **不任意去掉中文内部拉丁名**；中英文物种冲突的输入仍需核对。积雪草标准英文名在旧检索中实际已能由 ID 命中，报告的这一漏识别判断未成立。
- **不合并所有 PEG/PPG Dimethicone**；旧泛类 `Dimethicone Copolyol` 与 PEG-12 具体成分保留为不同记录，未知编号不能强行精确识别。
- **不宣称全部中文名已按中国法定目录校正**，也不把欧盟名称词汇表当作使用许可清单。
- **不新增资料不完整的缺口成分**。本轮仍为 152 条既有身份；扩充需要完整名称、角色、来源、模块和匹配边界。

报告中的西曲氯铵欧盟附录 III 编号也已按原文修正为 265，没有沿用报告所写的 286。其他报告建议的采纳边界见以上三个详细记录。

## 仍待核实的边界

- D6 在欧盟**淋洗化妆品**中的具体适用日期解释仍未解决；已记录所读条款，不虚构确定的生效日。
- 中国法规、药品批准范围和《已使用化妆品原料目录》原始附件尚未逐项核完，不能由欧盟或美国资料推断中国结论。
- 部分 CIR／SCCS 原文、笼统文献简称、精确物性数据和三个供应商／牌号归属仍待核对；资料列继续显示待核实。
- 完整配方的浓度、pH、原料等级、沉积／洗脱行为和个人过敏史未进入网站匹配。当前受控条件仍是单成分展示筛选规则，不是整瓶产品评分或临床判断。
